# understanding

Skills that raise your understanding of the project at hand to the level the work demands.

- **[lets-work](./lets-work/SKILL.md)**: Session entrypoint. Briefs you on how the project drifted from your recorded mental model, then sets the session's working frame.
- **[checkpoint](./checkpoint/SKILL.md)**: Exit ritual. Routes what the session taught you to its proper home and records the visit marker the next `lets-work` briefs from.
- **[organize-commits](./organize-commits/SKILL.md)**: Restructures a branch into reviewer-friendly, bisectable commits whose messages carry the why.
- **[why](./why/SKILL.md)**: Excavates why code is the way it is from the repo's own record, never a guess.
- **[explain](./explain/SKILL.md)**: Explains a change until you could defend it, grounded in the repo's record.
- **[depth-check](./depth-check/SKILL.md)**: Computes how much understanding a task demands and emits the questions to answer before coding.
- **[make-ticket](./make-ticket/SKILL.md)**: Drafts a ticket that records intent, not a solution.
